A conversational adaptive tutoring system that dynamically generates questions based on Subject, Topic, and Question Type, then personalizes feedback using Bayesian Networks, Hidden Markov Models, and Reinforcement Learning.



This is a chat-driven evolution of the original adaptive tutoring project, replacing a fixed question bank with dynamic, Gemini-generated questions across any subject the user chooses.



## Overview



Instead of picking from a form with dropdowns, the student talks to the tutor like a chat assistant:



1\. "What subject would you like to practice?"

2\. "What topic within that subject?"

3\. "MCQ, Descriptive, or Coding?"



Gemini then generates a fresh question matching those choices, and the same probabilistic reasoning pipeline from the original project (Bayesian Network, Hidden Markov Model, Reinforcement Learning) decides how to respond to the student's answer.

## Two Bayesian Networks (and why)



This project uses pgmpy for two different, complementary purposes:



1\. Live interactive Bayesian Network (modules/bayesian\_network.py)

&#x20;  Hand-specified CPDs, used during the actual chat session. This network reasons over variables collected live from the student (self-reported confidence, hint usage) which have no equivalent in any historical dataset, so its probabilities are specified based on domain reasoning rather than learned.



2\. Dataset-driven Bayesian Network (dataset\_bayesian\_network.py)

&#x20;  CPDs learned directly from real data using pgmpy's BayesianEstimator, applied to the UCI Student Performance dataset (Cortez, 2008). This demonstrates genuine parameter learning from a real, sourced dataset: given a student's study time, past failures, and absences, the model predicts P(Pass) using probabilities computed from 649 real student records, not hand-picked numbers.



Together, these show both sides of Bayesian Network usage: real-time probabilistic reasoning for live personalization, and data-driven parameter learning validated against real academic records.

\- pgmpy -- Bayesian Network construction, inference, and parameter learning

\- hmmlearn -- Hidden Markov Model for calibration state inference

\- ucimlrepo -- fetching the sourced UCI dataset

\- Streamlit -- conversational chat-style web UI



## Limitations / Future Work



\- The live-interaction BN and the dataset-learned BN currently operate on different variable sets, since no public dataset captures live confidence/hint-usage signals; a natural next step is collecting real usage logs from this system to eventually learn the live network's parameters too.

\- RL agent uses tabular Q-learning; a larger state space would need function approximation.

\- Question generation depends on the Gemini API; a local fallback question bank could improve reliability if the API is unavailable.
